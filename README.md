# Shop-Now React

Shop-Now React is a React + Vite product catalog that uses the Fake Store API for product data, categories, and product details.

## Tech Stack

- React 18
- React Router
- Vite

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run preview` serves the production build locally.

## Features

- Browse products by category
- Search the catalog from the home page
- View product detail pages
- Save and remove items from a wishlist stored in local storage
